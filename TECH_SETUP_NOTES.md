# Технические решения и настройки

> Этот файл фиксирует решения, принятые в чате, чтобы Claude Code не переспрашивал и не угадывал.

---

## Подход к сборке сайта (решение по умолчанию)

Сайт собирается как статический: каждая страница — готовый файл, отдаётся мгновенно, без сложного сервера.
Требование из дизайн-документа («контент должен быть в HTML при первом ответе сервера, без JS не должен пропадать текст») выполняется этим подходом естественно.

Единственное исключение — блог: туда со временем будут добавляться новые статьи, значит нужен способ пересобирать сайт при публикации новой статьи (см. ниже).

Хостинг: подойдёт простой/бюджетный хостинг, спецнастройка nginx не обязательна при таком подходе — эту часть дев-заметок («настроить кэширование на nginx на reg.ru») можно снять с требований.

## Публикация статей блога

Публикует человек без навыков разработки. Механика: новая статья добавляется как файл с текстом (по образцу существующих), затем сайт пересобирается и статья появляется на сайте. Без отдельной админ-панели с логином/паролем — она не нужна для одного автора и создаёт лишнюю точку отказа.

## Приём заявок с форм сайта → Telegram

Заявки с формы (главная, страницы услуг, /contacts) должны прилетать в Telegram.

**Что нужно для настройки (сделать один раз):**
1. В Telegram открыть **@BotFather** → команда `/newbot` → придумать имя бота → получить токен (строка вида `123456:ABC-DEF...`).
2. Написать боту любое сообщение, затем открыть в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — там будет число `chat_id` (куда слать заявки).
3. Токен и chat_id передать при настройке — дальше это делает код автоматически.

Хранить токен нужно как секрет (переменная окружения), не хардкодить в открытом коде страницы.

## Шрифты

Onest + Literata должны быть самохостящимися (файлы шрифтов лежат на самом сайте), не грузиться с Google Fonts CDN — в России это может работать нестабильно. Действий от заказчика не требуется, это делается на этапе сборки.

## Единая константа цены

**Цена подтверждена: 6500 ₽ на все услуги.** Выносится в конфиг одним значением, используется во всех текстах, микроразметке (`Offer.price`) и на всех страницах услуг — при изменении меняется в одном месте.

> Историческая справка (не использовать как факт для сайта): в интервью с экспертом упоминались черновые цены 4000 ₽ / 4500 ₽ до пересмотра. Финальная цена для сайта — 6500 ₽, подтверждена.

## Прочие константы для конфига
Контакты, адрес очного приёма, ссылки на мессенджеры (WhatsApp/Telegram/MAX), реквизиты (ИНН, самозанятая), время ответа — всё в одном конфиг-файле, не разбросано по страницам.

## Открыто (см. OPEN_QUESTIONS.md)
- Гео-охват «онлайн по всей России» — не подтверждено окончательно, сейчас используется как факт в текстах.
- Лид-магниты/гайды (платный ~900 ₽ и бесплатные PDF, упомянутые экспертом в интервью) — в текущей структуре не заведены как отдельные блоки/страницы. Решить, делаем на старте или после запуска.
